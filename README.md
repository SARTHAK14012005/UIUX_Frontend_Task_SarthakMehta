# DroneTV — UI/UX & Frontend Development Assignment

## Project Overview

This project is a responsive UI/UX and frontend implementation created as part of the UI/UX Designer & Frontend Developer Internship assignment.

The concept is designed around DroneTV as an aerial technology ecosystem covering drone technology, GIS, AI, industry insights and training.

## Screens Designed

The project includes five primary desktop screens:

* Home / Landing Page
* Services
* Courses / Training
* Login
* User Dashboard

A responsive mobile Home design was also created in Figma, with responsive behavior implemented across the frontend.

## Design Approach

The design uses a modern, premium technology-focused visual direction with:

* Dark navy interface
* Orange accent color
* Strong visual hierarchy
* Card-based content organization
* Responsive layouts
* Clear calls-to-action
* Consistent spacing and typography
* Mobile-friendly navigation

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Figma

No frontend frameworks or libraries were used.
